# 디자인 기록 — 스크린샷

`npm run dev` 실행 중에 `npm run design:screenshots`로 재생성할 수 있다.

- `01-landing.png` — 랜딩 페이지. 서비스 한 줄 설명과 워크스페이스 미리보기.
- `02-workspace.png` — 워크스페이스(완료 상태). 채팅·코드 에디터·미리보기 3분할 레이아웃.
- `03-search.png` — 가이드 검색(결과 상태). 인용 출처가 헤딩 경로로 표시된 검색 결과.
- `04-guides.png` — 가이드 관리(기본 상태). 업로드된 가이드 목록과 청크 미리보기.

프롬프트 작성 배경은 `docs/v0-prompts.md` 참고.
